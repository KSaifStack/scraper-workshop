# Scraper Workshop

A beginner-friendly workshop on web scraping with Python. You'll use `requests` to download a real web page and BeautifulSoup to pull structured data out of it: in this case, every book title and price on [Books to Scrape](https://books.toscrape.com/), a site built specifically for practicing scrapers.

## Prerequisites

- Python 3.x
- [VS Code](https://code.visualstudio.com/) (or any editor)

## Setup

Clone the repo and install the dependencies:

```bash
git clone https://github.com/KSaifStack/scraper-workshop.git
cd scraper-workshop
pip install -r requirements.txt
```

## Run it

Start with the skeleton, which has the four steps laid out with blanks to fill in:

```bash
python scraper_starter.py
```

Stuck? Compare your work against the fully commented solution:

```bash
python scraper_solution.py
```
